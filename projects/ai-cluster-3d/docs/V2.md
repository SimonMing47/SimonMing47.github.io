# v2：资源层级、全局定位与组网视图

## 三种相互联动的阅读方式

左侧是真正的递归资源树，不再把所有子部件限制为一级缩进。机柜、服务器、加速板、处理器封装、HBM和计算核分别处于各自层级。搜索保留命中节点的祖先路径；折叠状态在浏览器本地保存；方向键可以在目录中移动。

中央提供三维拆解与二维线框两种视图。三维图解释部件位置与结构，线框图解释连接、协议边界和流向。右上角全局定位图始终保留资源上下文，高亮当前所属区域，并以完整面包屑标出正在阅读的子部件。这个图是知识导航，不是实际资产定位或实时告警地图。

线框图覆盖12类关系：全局资源、代际柜级结构、服务器内存域、计算与本地存储、Leaf–Spine、交换机数据/控制面、供电、冷却、双向光路、提交与完成、存储、域内与域间互联。每类可以手动选择，也可以随当前资源自动切换。默认适配整个画布；放大后可滚动查看。

## 概念展开

47个资源节点各增加三段详细说明，共141段，解释位置与组成、工作与连接、例子与判断边界。缩写支持悬停及点击查看定义。产品说明和厂商对照独立于通用概念，避免一个术语被错误推广到所有代际。

关键区分包括主机DRAM与设备HBM、Cube/Vector的不同本地工作区、Unified Buffer与UnifiedBus、PCIe与设备紧耦合互联、控制面与数据面、RDMA请求与CQE完成记录，以及供电/散热和业务数据路径。

原有95条故障知识、关联资源和判断边界继续保留。公开数据不包含原环境的生成开关、恢复配置和修改时间。
