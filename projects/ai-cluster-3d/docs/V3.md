# AI Infra 全栈知识图谱 v3

本版在硬件三维与组网图谱上补充75个软件知识模块，与47个硬件节点组成122个知识节点。原有95条公开故障说明继续保留。它是静态知识网站，不连接真实设备，不执行恢复操作。

## 阅读方式

左侧在硬件、软件与全栈之间筛选。软件默认展示逻辑架构、流程、时序或泳道；“承载硬件3D”仅显示关联硬件，不将软件画成额外板卡。右上角的全栈定位随当前位置高亮。

每个软件模块包含定义、位置与职责、工作过程、工程例子、适用边界与类比。事实解释附来源；类比与推导明确标记为原创说明，不当作厂商实现。目录、图节点和缩写支持鼠标悬停及键盘焦点预览。完整解释中的段落可以独立收藏。

软件覆盖节点使能，CANN/AscendCL/CUDA，执行与编译，容器和隔离，Kubernetes/MindCluster/Volcano/Slurm/Ray，训练与HCCL/NCCL通信，并行/状态分片，推理引擎与KV管理，P/D分离，以及可观测性、安全、制品和性能评估。范围是这些已列出的核心模块，不声称覆盖所有厂商的全部组件或版本特性。

新增26类逻辑图：17类架构/数据流、8类时序和1类连续批处理泳道。保留12类硬件关系图，总计38类。图的空间距离不代表执行耗时；依赖箭头不是原厂机械图或未公开接口协议。

## 收藏与隐私

模块、解释段落、故障可分别收藏并保留产品视角。每条可写最多1600字符备注。收藏只使用 `ai-infra-atlas.bookmarks.v1` 这个localStorage键，不上传GitHub或其他服务器。支持搜索、移除、JSON导出及合并导入；重复项保留现有备注。导入只接受已知知识点和字段，最大2MiB、1200项；备注按文本显示。

浏览器禁止存储、内容损坏或写入失败时，界面提示当前仅保留于页面内，并提供导出。直接用file://打开时，持久化行为依浏览器而异，不能保证移动文件后仍能访问原收藏。HTTP/HTTPS部署的收藏按浏览器源隔离；清理网站数据会删除它们，跨设备迁移需要导出再导入。

## 事实核查范围

软件使用65项官方文档、官方仓库或原始论文；来源记录版本、核读日期（2026-09-23）和支持范围。全站含此前来源共97项。旧资料入口与本轮正文核读分开标记，不能把一个通用参考链接当作已经核实全部专有故障码、阈值或当前功能支持的证据。

MindCluster官方开发仓库已经出现A5适配和切分说明，因此不再说A5没有公开软件证据。但这不证明所有发布版都支持，也不能证明A5与某个公开Atlas型号对应。A5物理柜数、板位和代际映射继续不做推断。

PyTorch 2.8、MindSpore 2.6及MindFormers r1.3等资料用于注明版本的原理说明，不作为当前安装组合。历史论文的性能数字没有迁移到本网站的硬件模型。原故障数据的生产配置、开关、规则和修改时间不进入公开仓库。

## 构建与检查

```bash
node tests/structure.test.cjs
node tests/software.test.cjs
python scripts/validate.py
python scripts/build.py
```

`dist/index.html` 是单文件离线版。源目录的index.html直接引用本地脚本与样式，不需要网络CDN或npm构建。

本地检查包括610个模型/产品组合、190个图/产品组合、资源关系、来源引用、有限几何值、图节点边界，以及收藏存储适配器的刷新读回、导入合并、无效内容拒绝和异常回退。浏览器测试遍历122个资源、375个软件说明段落，并检查悬停、收藏、备注、故障反向定位与响应式页面。
