# METRO RUSH：午夜喷绘与追逐逃脱

本文件描述 v6.0 已实现的设计。目标是让玩家知道为什么跑、失误后还有什么机会、什么时候完成一程，并让后期需要持续判断路线与动作。

## 1. 故事与一局的起承转合

凌晨 00:47，阿岚在中央车库给一列停靠的地铁完成涂鸦。巡线员老周巡查时发现了他，手电扫过车厢。阿岚收起喷罐，转身冲进轨道，目标是穿过封锁、抵达北桥出口。

玩家先经历短剧情，再接管奔跑；沿途积攒金币、选择事件路线、争取拉开追兵。出口处有一段明确的组合考验。成功抵达后可结束本次冒险，也可保留成绩继续深入旧线，前往下一个出口。巡线员仍在远处搜寻，新的失误会让他重新追近。

角色、涂鸦、服装、场景及配乐提示均为原创程序实现，不使用商业游戏素材。

| 时间 | 镜头与人物动作 | 玩家得到的信息 |
| --- | --- | --- |
| 0–2.2 秒 | 车身侧方镜头；右手拿喷罐，手腕摆动与喷雾粒子，车身逐笔出现 MR 涂鸦 | 我正在做什么 |
| 2.2–3.3 秒 | 巡线员出现，手电光点与警示音；阿岚回头、收手 | 为什么开始逃跑 |
| 3.3–5.2 秒 | 阿岚转向轨道，开始奔跑；镜头转入追尾视角 | 去哪里、首次失误如何处理 |
| 5.2 秒后 | 正式模拟赛道与计分，显示出口目标和追逐状态 | 立即接管操作 |

开场可点击按钮或按空格／回车跳过。跳过与完整播放使用同一条已生成路线，剧情中金币、距离和道具计时均不推进。剧情可暂停，失焦后自动暂停。

## 2. 碰撞、脱险与被抓

玩法采用清楚的三段反馈：拉开距离 → 失误后贴身追赶 → 再次失误被抓。追兵不会单纯因为时间经过就自动抓住玩家。

| 情况 | 实际结果 | 玩家看到的反馈 |
| --- | --- | --- |
| 有滑板保护时碰撞 | 消耗滑板，原有 1.4 秒保护；不增加追逐失误 | 滑板破裂、护身提示 |
| 已拉开距离时，无保护碰撞 | 增加一次失误；短暂脱险，进入危险追逐 | 踉跄、后撤／侧移、镜头轻震、老周靠近、追逐条变红 |
| 危险追逐中再发生独立碰撞 | 被抓；1.05 秒抓捕动作后显示结果 | 老周伸手、人物停稳、被抓原因及重试按钮 |
| 连续无伤跑动 | 追逐压力逐渐下降，最终恢复一次失误机会 | 距离拉开、红条退去、恢复提示 |
| 真正跳过路障或滑过横杆 | 在自然恢复外，进一步降低追逐压力 | 跳滑加分，可能提前触发恢复提示 |
| 拾取迷彩喷雾 | 立即降低 42 点追逐压力，出现约 3 秒烟雾 | 烟雾模型、身后烟团、道具说明；不提供护盾 |

普通脱险动作约 0.55 秒。迎面碰车优先侧移到能够安全落脚的邻轨；极端全轨堵车时，约 0.72 秒翻上当前车顶。脱险期间赛道、来车和计时一起冻结，避免动作尚未结束又迎来下一次撞击；结束后另有 1.1 秒短保护。

同一长车厢的持续接触只算一次事故。离开接触并结束保护后再次撞回同一列车，会重新判定。一次车顶碰撞不会关闭后续的横杆、车厢断口或其他课程障碍；在空中撞到车顶横杆，恢复会查询脚下实际承托面，落回屋顶。

## 3. 难度参数与后期变化

| 参数 | 休闲 | 经典 | 极限 |
| --- | --- | --- | --- |
| 初始速度 | 50 km/h | 65 km/h | 83 km/h |
| 远程峰值上限约 | 122 km/h | 173 km/h | 214 km/h |
| 首次失误后无伤恢复约 | 7 秒 | 10 秒 | 13 秒 |
| 每次干净跳滑额外降低压力 | 5 点 | 4 点 | 3 点 |
| 每程开始寻找出口的距离 | 1200 米 | 1500 米 | 1800 米 |
| 出口封锁波数 | 4 波 | 5 波 | 6 波 |
| 开局滑板 | 2 块 | 1 块 | 1 块 |
| 基础计分倍率 | ×1 | ×1.5 | ×2 |

追逐压力初始为 18，首次失误变为 88，低于 55 恢复容错。自然下降速度为每秒 `34 / 无伤恢复秒数`，HUD 秒数是保守取整的估计。动作会额外缩短时间，因此实际恢复可能更快；暂停和脱险冻结期间不计算。

前 420 米热身，随后保持已有的「巡航、提速、疾跑、回落、恢复、蓄势」循环，每轮约 980–1220 米。周期、峰值和布局随种子变化；后期速度继续起伏，巡航基准也逐步提高。难度来自速度变化、需要组合动作的封线、更多突围波次，以及更长的失误压力窗口。

到达寻找出口的距离后，在当前完整路段之后安插封锁，所以实际终点会比表中的基础距离更远。预告阶段显示准确出口距离；继续下一程按当时累计里程重新安排，不重置速度进程。

## 4. 出口突围：一程的高潮与成功结算

出口不是跑够米数自动获胜。玩家需要完成整段、全程无碰撞，逐波获得动作进度：

1. **车潮换道**：看预告和信号，穿过交错迎面列车；每波只在实际通过后记一次。
2. **选道＋跳跃**：施工围挡封住一轨，混合列车与低障碍，选通路后跳过。
3. **选道＋滑铲**：换一组封线，沿可通行轨滑过横杆。
4. 重复组合至本难度的 4／5／6 波，并通过绿色出口拱门。

金币、随机事件仍提供沿途节奏；目标面板优先显示突围进度与剩余距离。护盾撞破和喷气绕过不能替代动作达标；发生碰撞会明确显示这一段未达标。无伤通过才结算出口奖励：基础 1700–1900 分（随事件强度）与 70 金币，连续三次事件达标仍叠加连胜补给。

成功时冻结赛道和计时，显示出口名称、得分、脱身次数、最高时速和本局成果。「挑战下一片区」保留成绩、金币、道具、任务进度和累计距离，恢复远距离追逐状态，并安排下一个出口；返回起点则结束本局。

突围未达标会继续跑，在该段终点之后至少约 650 米再安排出口。已有积分保留，连胜中断。失败不会突然重置关卡，也不会立即弹出结束画面。

## 5. 沿途的选择与奖励

五类随机事件继续使用不相邻重复的洗牌袋，出口突围单独按行程安排。

| 内容 | 核心乐趣 | 与追逐／目标的关系 |
| --- | --- | --- |
| 限段快递 | 追随徽章换道，争取全部真实触碰 | 节奏较缓，可积累自然恢复时间 |
| 跳滑接力 | 连续完成跳跃和滑铲 | 干净动作同时降低追逐压力 |
| 晚点车潮 | 看车灯与信号，判断交错来车 | 高速度下增加判断压力 |
| 分岔夺宝 | 地面蓝色路线或高奖励金色车顶路线，可中途改变 | 玩家主动承担更高风险换收益 |
| 施工封线 | 每波不同封轨，选道和跳滑同时执行 | 左右移动无法替代全部动作 |
| 车顶与山洞 | 上坡、屋顶跑动、跨车厢、滑杆、下坡及洞顶限高 | 立体路线与时机变化 |
| 三事件连胜 | 额外积分、金币和滑板补给 | 连胜值得争取，失误也有明确代价 |
| 循环任务 | 收币、真实跳滑、新增里程和事件达标轮换 | 后期继续有短期目标 |

七种道具分工：磁铁帮助收币，双倍提高得分，超级跳跃改变可达路径，喷气提供短暂飞行，滑板主动保命，礼盒给予随机收益，烟雾降低追逐压力。磁铁只吸金币，所有计时和飞行轨迹支持暂停。

## 6. 角色与界面反馈

阿岚保留原有帽檐、耳机、连帽衫、背包、鞋底及关节细节，增加喷涂、回头、起跑、踉跄和被抓姿态。老周使用独立角色实例，穿深蓝制服，有帽子、胸章、腰带、对讲机、反光条和手电。两人共用骨骼解算结构，拥有各自的动作状态。

追兵跟随玩家过去的跑动轨迹，包括换道、跳跃、坡面和车顶高度；压力决定跟随距离。玩家喷气飞行时，追兵离开画面，不会无装备浮空。被抓时双脚逐渐站稳，手臂伸出；暂停同时冻结身体、粒子、镜头与追踪轨迹。

界面只增加必要的状态：开场底部字幕与跳过按钮、HUD 追逐条、任务面板中的当前出口、出口／被抓结算。危险用文字与颜色共同提示。手机仍可滑动，桌面仍用方向键或 WASD；无需为追逐学习新按钮。减少动态效果偏好下关闭镜头抖动与速度视野变化，烟雾使用静态分布。

## 7. 公平性和验收

正确的规划路线必须在 **零碰撞、零容错消耗** 下走通。新容错机制不作为关卡可达性的证明。动作间隔按未来最高速度预留，来车预警和实际运动共享速度预测；高速帧仍用扫掠判定。随机源分离，领取奖励不改变后续路线。

自动测试覆盖剧情、跳过、暂停、首次撞击、同车连续接触与重新进入、贴身抓捕、车顶空中恢复、烟雾与滑板优先级、事件污损、出口成功／失败／继续，以及角色滑铲净空和抓捕首帧连续性。现有地面／屋顶／洞内路线、变速来车、金币及全部道具回归一并运行。

数值渲染检查了 3,432 帧，覆盖三难度、桌面／手机尺寸和减少动态效果。84 组暂停前后快照完全一致；244,070,536 个输入数值均有限，无批次溢出。人物圆角块峰值 162／256，场景方块峰值 1,891／14,000。检查覆盖剧情、双角色、飞行、脱险和出口突围。没有进行浏览器画面或真实手机试玩；数值可达性与模型边界验证不能代表已经验证玩家体验。
