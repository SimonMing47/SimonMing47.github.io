# METRO RUSH · 地铁疾跑

原创 3D 无尽跑酷小游戏。黄昏城市轨道、第三人称跟随镜头、三条轨道和可直接游玩的完整循环，支持桌面键盘与手机触屏。

## 开始游戏

需要 Node.js 20 或以上，无需安装依赖：

```bash
npm start
```

浏览器打开 `http://localhost:3000`。也可以运行 `python3 -m http.server 3000 --directory dist`。不要直接双击 HTML 文件，浏览器的 ES Module 需要 HTTP 服务。

## 操作

| 动作 | 键盘 | 手机 |
| --- | --- | --- |
| 左右换道 | ← / → 或 A / D | 左右滑动，或点击方向按钮 |
| 跳跃 | ↑ / W / 空格 | 向上滑动或点击 ↑ |
| 滑铲；空中快速落地 | ↓ / S | 向下滑动或点击 ↓ |
| 暂停 / 继续 | P / Esc | 右上角暂停按钮 |

低路障需要跳跃或换道；高架障碍需要滑铲或换道；列车必须换道。磁铁生效 8 秒，吸附附近三条轨道上的金币。速度随距离增加，最高 129.6 km/h。得分 = 整数距离 + 金币数 × 10。

每组障碍保证有一条完整空道，相邻障碍组间隔至少 32 米。第一次遇到障碍前有练习空间。游戏切到后台或窗口失焦时自动暂停，回来后手动继续。最高距离和音效开关仅保存在当前浏览器本机，禁用本地存储时仍可正常游戏。

## 技术实现

- 原生 JavaScript ES Modules + WebGL 2，无第三方运行依赖、CDN、遥测、账号或后端。
- 真正的透视 3D 渲染，实例化绘制、定向光照、距离雾、关节角色动画、金币粒子。
- 固定 120 Hz 游戏模拟，渲染使用 `requestAnimationFrame`；分辨率倍率上限 1.75，批量实例复用 GPU 缓冲区。
- 玩法与渲染分离，种子随机数支持可重复的关卡验证。
- Web Audio 程序生成音效，默认静音，用户开启后播放。
- 可选 WebMCP：支持该接口的浏览器可调用 `get_run_state` 和 `control_run`；不支持时不影响游戏。
- 所有角色、场景、图标和音效均由代码原创生成，不包含商业游戏素材。

## 文件

```text
dist/
  index.html     游戏界面
  style.css      响应式样式
  game.js        输入、界面、音效与游戏循环
  engine.js      纯玩法模型、碰撞与关卡生成
  renderer.js    WebGL 2 渲染和程序化 3D 场景
  icon.svg       图标
scripts/serve.mjs 本地静态服务
tests/engine.test.mjs 玩法及矩阵验证
```

## 验证

```bash
npm test
npm run check
```

覆盖跳跃、换道、三类障碍碰撞、暂停与恢复、金币单次计分、磁铁期限、生成路线可通行性、速度上限、重开重置和 3D 矩阵组合。浏览器实机操作和 WebMCP 宿主验证未在当前流程执行。

## 部署

将 `dist/` 中的内容部署到任意静态网站服务即可。所有地址均为相对路径，支持部署在子目录。无需构建或联网加载素材。

浏览器需要支持 WebGL 2。若设备关闭了硬件加速、图形上下文丢失或浏览器不支持，会显示明确提示。
