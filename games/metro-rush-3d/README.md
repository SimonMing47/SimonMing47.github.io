# METRO RUSH · 地铁疾跑 v2.1

原创 WebGL 2 三维跑酷游戏：三档难度、五级节奏、六种奖励、连币倍率和本局挑战。支持桌面键盘和手机滑动，无第三方运行依赖。

## 本地运行

需要 Node.js 20+，无需安装依赖：

```bash
npm start
```

打开 `http://localhost:3000`。也可运行 `python3 -m http.server 3000 --directory dist`。ES Modules 需通过 HTTP 加载，不要直接双击 HTML。

## 三档难度

| 难度 | 初速 → 最高速度 | 基础积分倍率 | 开局滑板 | 道具时长 | 障碍节奏 |
| --- | --- | --- | --- | --- | --- |
| 休闲 CHILL | 50.4 → 86.4 km/h | ×1 | 2 | 标准 ×1.25 | 换道起步，逐步加入整排跳跃与滑铲 |
| 经典 FLOW | 64.8 → 122.4 km/h | ×1.5 | 1 | 标准 | 整排跳滑与列车混合，每 8 排有 4 排动作要求 |
| 极限 RUSH | 82.8 → 151.2 km/h | ×2 | 1 | 标准 ×0.85 | 更早引入连续动作，每 6 排有 4 排动作要求 |

每档内部由 LV.1 热身起跑递进到 LV.5 极限冲刺。休闲／极限每 500 米升一级，经典每 600 米升一级。速度渐进增加，生成间距随阶段收紧并保留速度相关下限。关卡由换道、三道低障碍、三道横杆及“一列车＋两低障碍／横杆”组成；整排路段要求跳跃或滑铲，不能仅靠左右移动通过。规划通路最多相邻换一道，间距至少为 `max(难度下限, 预计速度 × 1.4 + 9.4)` 米，覆盖超级跳跃落地、滑铲恢复及列车长度。距动作路段约 1.8 秒显示预告。各难度分别保存本机最高分及最远距离，旧版最远距离保留为经典模式纪录。

## 六种 bonus

| 奖励 | 经典模式时长 | 行为 |
| --- | --- | --- |
| 金币磁铁 | 10 秒 | 前方 9 米内、接近当前高度的三轨金币沿轨迹飞入角色，接触后计数 |
| 双倍积分 | 12 秒 | 新获得的跑酷积分 ×2，已得分不追溯翻倍，挑战固定奖励除外 |
| 超级跳跃 | 10 秒 | 增强跳跃高度，可越过列车；到期不截断当前跳跃 |
| 喷气背包 | 7 秒 | 自动升空，无碰撞，换道收集空中金币；到期平稳落地并短暂保护 |
| 护航滑板 | 15 秒 | 拾取补充库存（上限 3）；按 B／双击启用，抵挡一次碰撞后消耗 |
| 神秘礼盒 | 即时 | 随机得到 25／50 金币、一块滑板或一种增益，结果随关卡种子可复现 |

磁铁激活后显示角色周围双层光环、随身磁铁、环绕粒子与金币飞行光迹。吸附过程为 0.18–0.36 秒，暂停冻结，磁铁到期前已开始吸附的金币继续完成飞行。普通金币使用与画面一致的固定高度及扫掠接触判定，取消前方 1 米提前入账。

所有道具都有不同的立体模型、统一图标、逐项图鉴说明和 HUD 反馈；计时道具可同时显示。相同道具刷新时长，不无限累加。滑板库存已满时再拾取转为 20 金币。飞行期间暂停已有滑板计时。滑板破裂后保护 1.4 秒，喷气降落后保护 1.35 秒，避免同一障碍连续触发。

### 连币和本局挑战

连续收集 20 枚金币获得 ×1.5 连币倍率，40 枚获得 ×2；超过当前难度的连币宽限时间未捡到金币则归零。计分倍率为「难度 × 连币 × 双倍积分」，仅对当时获得的分数生效。

基础距离分为每米 1 分，金币为每枚 10 分，成功跳跃／滑铲穿过本轨障碍额外获得 30 基础分。礼盒、溢出滑板的金币同样计入总金币。以下挑战每局仅结算一次，奖励分固定、不受倍率影响：

- 收集 50 金币：+500 分。
- 跑过 800 米：+800 分。
- 拾取 3 个道具：+600 分。

成绩页展示本难度得分、距离、金币、最高连币、道具拾取次数、护身次数及奖励分。

## 操作

| 动作 | 键盘 | 手机 |
| --- | --- | --- |
| 左右换道 | ← / → 或 A / D | 左右滑动，或方向按钮 |
| 跳跃 | ↑ / W / 空格 | 上滑或 ↑ |
| 滑铲／空中快速落地 | ↓ / S | 下滑或 ↓ |
| 启用滑板 | B | 双击游戏场景或点击滑板按钮 |
| 暂停／继续 | P / Esc | 右上角暂停 |

零散低路障／横杆可换道，整排低路障必须跳跃、整排横杆必须滑铲，列车混合段需同时选道与动作；超级跳跃可跃过列车。喷气期间只允许换道和计时保护，不允许手动跳跃／滑铲。切到后台或失焦自动暂停，暂停冻结物理、增益和连币。奔跑时打开指南会暂停，关闭后自动回到奔跑；从已暂停界面打开则保持暂停。

## 验证与实现

```bash
npm test
npm run check
```

30 项自动化测试覆盖原有玩法及本轮回归：普通金币接触和高速扫掠、换道／跳跃／滑铲高度、磁铁逐步吸附与入账、暂停／到期时间边界与磁铁当帧激活、连币与奖励、三轨障碍不能钻缝或高速穿透、四种动作布局的正确／错误操作、60 组难度与种子的通路约束，以及三难度最高速下 36 组正常／超级跳跃、120 Hz／20 Hz、每组 2200 米的连续跳滑模拟。

- 原生 ES Modules、WebGL 2 实例化渲染、光照／雾效、角色关节动画、磁场与吸附轨迹、道具粒子和 Web Audio 合成音效。
- 固定 120 Hz 逻辑模拟，`requestAnimationFrame` 渲染，像素倍率上限 1.75。
- 所有角色、场景和道具由程序生成，不包含商业游戏素材；无外部 CDN、遥测、账户、广告或付费功能。
- 成绩、难度偏好和音效开关只保存在当前浏览器；禁止本地存储时仍可运行。
- 可选 WebMCP 提供 `get_run_state`、`select_difficulty`、`control_run`，直接复用 UI 的状态和操作。
- 当前流程未执行浏览器实机或 WebMCP 宿主测试；逻辑、静态资源和着色器验证不能替代设备实测。

## 代码与部署

`dist/engine.js` 为纯玩法模型，`dist/renderer.js` 为 3D 渲染，`dist/game.js` 负责输入／UI／音效，`dist/index.html` 和 `dist/style.css` 为界面。静态服务器在 `scripts/serve.mjs`，测试在 `tests/engine.test.mjs`。

部署 `dist/` 内容到任意静态网站服务即可，资源全部使用相对地址，支持子目录部署。需要 WebGL 2 和硬件加速。

GitHub 中位于 `games/metro-rush-3d/`，保持独立启动和测试。个人站点 Eleventy 尚未配置该目录透传；独立试玩站点为 https://metro-rush-ming.mingxing47.chatgpt.site（需拥有站点访问权限）。
