# METRO RUSH · 地铁疾跑 v6.0

原创 WebGL 2 三维跑酷游戏：斜坡与车顶路线、迎面列车、五个随机街区、山洞场景、五类随机事件与出口突围、三档难度、七种奖励和连币挑战。支持桌面键盘和手机滑动，无第三方运行依赖。

## 午夜喷绘与追逐逃脱

5.2 秒原创开场：阿岚喷涂停靠列车 → 巡线员老周发现 → 转身开跑。可点击或空格跳过，剧情不推进赛道和道具计时。

首次无保护碰撞会踉跄脱险，追兵逼近；贴身再撞才被抓。连续无伤约 7／10／13 秒（休闲／经典／极限）可恢复机会，真实跳滑动作能缩短追逐。滑板优先护身，新增迷彩喷雾降低追逐压力。

每程以抵达出口为目标，出口前有 4／5／6 波车潮、跳跃与滑铲封锁。成功后暂停并结算，可保留分数继续下一程；失败则寻找之后的出口。

完整剧情分镜、碰撞优先级、追逐参数、关卡与反馈规则见 [详细设计](DESIGN.zh-CN.md)。

## 本地运行

需要 Node.js 20+，无需安装依赖：

```bash
npm start
```

打开 `http://localhost:3000`。也可运行 `python3 -m http.server 3000 --directory dist`。ES Modules 需通过 HTTP 加载，不要直接双击 HTML。

## 随机旅程与事件

中央车站之后，随机穿行蔚蓝港区、林间旧线、落日峡谷、霓虹夜市；相邻街区不重复。街区约 360–510 米，建筑绑定世界位置，天色与雾色在边界渐变。港区有集装箱、吊机和水面，林间有乔木和木门，峡谷有岩层与桥墩，夜市有霓虹招牌、摊位与灯笼；车顶路段随机穿过山洞。

| 事件 | 操作与目标 | 奖励 |
| --- | --- | --- |
| 限段快递 | 跟随路线换道，亲自触碰 3 枚蓝色徽章；磁铁只吸金币 | 600 分 +25 金币 |
| 跳滑接力 | 干净完成 3–4 组跳滑，较高强度混入列车；护盾／飞行绕过不计动作 | 850–1050 分 +30 金币 |
| 晚点车潮 | 提前看信号，避开 3–4 波交错迎面列车；等级提升增加来车速度 | 900–1100 分 +35 金币 |
| 分岔夺宝 | 同一段提供中轨蓝色地面与侧轨金色车顶路线；每个检查点只算一枚，可中途改变路线 | 基础 500–700 分 +20 金币；每枚车顶徽章再加 200 分、10 金币 |
| 施工封线 | 黄黑围挡封住一轨，另外两轨同步要求跳跃或滑铲；每组调整封线位置 | 1050–1250 分 +40 金币 |

事件提前约 4 秒预告，在原目标面板内显示进度、剩余距离和结算，不新增遮挡操作的弹窗。完成时一次性发放固定积分和金币（金币按每枚 10 分计入）；未达标不扣分。记录本局完成次数与最佳连续完成次数。每连续完成三个事件，额外奖励 500 分、30 金币与一块滑板；库存已满则滑板转为 20 金币。失败重置连胜，已得奖励不扣回。车顶礼盒安排在徽章之后，避免喷气奖励使玩家错过终点。

随机事件使用洗牌袋，每袋覆盖五类，跨袋不相邻重复；内部轨道、跳滑顺序、混合列车、车厢长度和是否进洞均有变化。普通路段按随机强度编排，高压事件结束后有两段宽松补给。连续相同动作受限，规划通路保持最多换一个相邻轨道和速度相关的动作间隔。分岔夺宝的地面路线不放迎面列车，金色高奖徽章必须真实触碰；两条路线同一检查点不能重复领奖。关卡、街区、道具顺序与礼盒奖励使用独立随机源，礼盒结果不会改变之后的路线。

## 人物与动作重构

- 清除车顶边缘细线及跨过车顶的架空细线，保留可跑的平整车顶与坡道引导。
- 角色改为圆角服装、曲面胸腔和细分头部，加入五官、耳机、帽檐、背包缝线与拉链、连帽衫抽绳、手指、鞋带和分层鞋底；角色网格独立批处理，不提高整个场景的网格密度。
- 骨盆、胸腔、头部、肩肘腕及髋膝踝分别驱动；脚掌落点通过双骨骼 IK 解算膝盖。跑步分为支撑与摆腿阶段，步频随速度调整，接触期脚掌后移速度匹配轨道；每只脚单独采样坡度和车顶边缘。
- 起跳、上升、顶点、下落、落地压缩、滑铲、起身恢复、滑板、喷气、换道和碰撞有不同姿态。落地、跳跃和碰撞接收真实玩法事件；暂停冻结姿态，重开清除动作状态。
- 滑铲开始时立即压低到碰撞净空，再在低姿态中伸腿，结束后平滑起身；完整头饰与背包计入站立 2.05 米／滑铲 0.72 米的网格边界验证。滑板与双脚共享坡面，滑铲时脚底仍位于板面上。

## 持续变速与三档难度

| 难度 | 初速 | 巡航基准 | 远程峰值上限约 | 基础积分倍率 | 开局滑板 |
| --- | --- | --- | --- | --- | --- |
| 休闲 CHILL | 50 km/h | 86 km/h | 122 km/h | ×1 | 2 |
| 经典 FLOW | 65 km/h | 122 km/h | 173 km/h | ×1.5 | 1 |
| 极限 RUSH | 83 km/h | 151 km/h | 214 km/h | ×2 | 1 |

前 420 米渐进热身；之后按「巡航 → 提速 → 疾跑 → 回落 → 恢复 → 蓄势」持续循环。周期约 980–1220 米、峰值随种子和轮次变化；巡航基准仍随里程增长，达到旧上限后继续逐渐增加至旧基准的 114%。曲线平滑连接，后期也会反复提速、减速；保留有界峰值，避免无限加速到无法操作。等级继续随距离递进，不再停在 LV.5。

HUD 显示实际时速、当前变速阶段与距下一阶段的距离，原进度条改为速度阶段进度。加速／疾跑／恢复有简短文字和音效提示，镜头随速度缓慢扩大视野；减少动态效果偏好下固定视野。成绩页新增本局最高时速。

列车 ETA 与玩家移动共用同一速度曲线，预测用数值积分，实际移动用中点积分。事件生成范围按最高速度预留超过 5 秒，提前约 4 秒预告；地面动作间距采用未来区间最高速度，车顶车厢长度留出超级跳落地空间，车厢缝按区间最低速度控制，徽章按真实行进时间放在落地窗口。变速不能制造瞬间贴脸障碍。

整排低障碍要求跳跃、整排横杆要求滑铲；施工与列车混合段同时要求选道与动作。各难度分别保存本机最高分及最远距离，旧版最远距离保留为经典模式纪录。休闲／经典／极限的道具时长系数仍为 1.25／1／0.85。

## 立体路线与迎面列车

普通车顶路线与随机事件交错生成，不再按固定短周期重复。路线由上坡、第一组列车、车厢间隙、第二组列车、下坡组成，整个路段统一生成，常规障碍不会插入坡口或落脚点。

- 斜坡可以直接跑上／跑下，车顶是真实承托面；可以再次起跳、滑铲，换道离开边缘后自然下落。地面侧面进入坡体或车厢仍会碰撞。
- 车顶布置金币、低障碍、横杆和末端礼盒，车厢断口需要提前跳过。空中下滑会快速下落，并在落地时衔接滑铲。
- 列车长度与坡道长度随速度调整，给动作与落地恢复留下时间。车顶路线下方仍是地面轨道，可从侧面跳下；迎面列车会经过邻轨。
- 来车有独立的 9／13／18 m/s 迎面速度，闭合速度为跑速加来车速度；采用真实前后位置做扫掠检测。车头暖色、闪灯、提示与喇叭共同预警，暂停冻结列车。
- 山洞包括岩石入口、拱顶、洞壁、灯带与壁灯；进出洞时照明与雾色平滑切换。按所在轨道和角色宽度计算拱顶净空；常规车顶动作与喷气可通行，起跳根据拱顶净空限制初速度，避免碰顶后过早落下；空中换道碰顶仍停止上升。
- 镜头随承托面高度平滑升降，在洞内限制镜头高度。HUD 显示地面／上坡／车顶／下坡／腾空及山洞状态。

## 七种 bonus

| 奖励 | 经典模式时长 | 行为 |
| --- | --- | --- |
| 金币磁铁 | 10 秒 | 前方 9 米内、接近当前高度的三轨金币沿轨迹飞入角色，接触后计数 |
| 双倍积分 | 12 秒 | 新获得的跑酷积分 ×2，已得分不追溯翻倍，挑战固定奖励除外 |
| 超级跳跃 | 10 秒 | 增强跳跃高度，可越过列车；到期不截断当前跳跃 |
| 喷气背包 | 7 秒 | 自动升空，无碰撞，换道收集空中金币；到期平稳落地并短暂保护 |
| 护航滑板 | 15 秒 | 拾取补充库存（上限 3）；按 B／双击启用，抵挡一次碰撞后消耗 |
| 迷彩喷雾 | 3 秒视觉效果 | 立即降低 42 点追逐压力；不提供碰撞保护 |
| 神秘礼盒 | 即时 | 随机得到 25／50 金币、一块滑板或一种增益，结果随关卡种子可复现 |

磁铁激活后显示角色周围双层光环、随身磁铁、环绕粒子与金币飞行光迹。吸附过程为 0.18–0.36 秒，暂停冻结，磁铁到期前已开始吸附的金币继续完成飞行。普通金币使用与画面一致的固定高度及扫掠接触判定，取消前方 1 米提前入账。

所有道具都有不同的立体模型、统一图标、逐项图鉴说明和 HUD 反馈；计时道具可同时显示。相同道具刷新时长，不无限累加。滑板库存已满时再拾取转为 20 金币。飞行期间暂停已有滑板计时。滑板破裂后保护 1.4 秒，喷气降落后保护 1.35 秒，避免同一障碍连续触发。

### 连币和本局挑战

连续收集 20 枚金币获得 ×1.5 连币倍率，40 枚获得 ×2；超过当前难度的连币宽限时间未捡到金币则归零。计分倍率为「难度 × 连币 × 双倍积分」，仅对当时获得的分数生效。

基础距离分为每米 1 分，金币为每枚 10 分，成功跳跃／滑铲穿过本轨障碍额外获得 30 基础分。礼盒、溢出滑板的金币同样计入总金币。开局有以下三个目标，奖励固定、不受倍率影响：

- 收集 50 金币：+500 分。
- 跑过 800 米：+800 分。
- 拾取 3 个道具：+600 分。

每组全部完成后立刻换下一组，从亲自收币、干净跳过路障、干净滑过横杆、继续跑过指定距离、完成事件中轮换。目标以新一组开始时的数据为基线，不追溯旧成绩；礼盒与事件奖励金币不算亲自收集，空跳、飞行绕过或护盾撞破不算干净动作。目标数与奖励逐步增加并有上限，完成次数持续累积。

成绩页展示本难度得分、距离、金币、最高连币、道具拾取次数、护身次数、挑战完成数、事件连胜和最高时速。

## 操作

| 动作 | 键盘 | 手机 |
| --- | --- | --- |
| 左右换道 | ← / → 或 A / D | 左右滑动，或方向按钮 |
| 跳跃 | ↑ / W / 空格 | 上滑或 ↑ |
| 滑铲／空中快速落地 | ↓ / S | 下滑或 ↓ |
| 启用滑板 | B | 双击游戏场景或点击滑板按钮 |
| 暂停／继续 | P / Esc | 右上角暂停 |

零散低路障／横杆可换道，整排低路障必须跳跃、整排横杆必须滑铲，列车混合段需同时选道与动作；超级跳跃可跃过列车。喷气期间只允许换道和计时保护，不允许手动跳跃／滑铲。切到后台或失焦自动暂停，暂停冻结物理、增益和连币。奔跑时打开指南会暂停，关闭后自动回到奔跑；从已暂停界面打开则保持暂停。

新增剧情与双角色执行独立数值渲染检查，具体结果见详细设计。此类检查验证矩阵、容量与暂停一致性，不等同于画面和设备实测。

- 原生 ES Modules、WebGL 2 实例化渲染、光照／雾效、角色关节动画、磁场与吸附轨迹、道具粒子和 Web Audio 合成音效。
- 承托面与障碍碰撞分离，角色高度统一使用脚底世界坐标；固定 120 Hz 逻辑模拟，`requestAnimationFrame` 渲染，像素倍率上限 1.75。
- 所有角色、场景和道具由程序生成，不包含商业游戏素材；无外部 CDN、遥测、账户、广告或付费功能。
- 成绩、难度偏好和音效开关只保存在当前浏览器；禁止本地存储时仍可运行。
- 可选 WebMCP 提供 `get_run_state`、`select_difficulty`、`control_run`，直接复用 UI 的状态和操作。
- 当前流程未执行浏览器实机或 WebMCP 宿主测试；逻辑、静态资源和着色器验证不能替代设备实测。

## 代码与部署

`dist/pursuit.js` 为追逐与出口参数，`dist/director.js` 为随机关卡编排，`dist/district-scenery.js` 为街区与事件场景，`dist/engine.js` 为纯玩法模型，`dist/renderer.js` 为场景与特效，`dist/character.js` 为角色骨架和外观，`dist/animation.js` 为姿态、步态和 IK，`dist/character-geometry.js` 为平滑网格，`dist/math.js` 为共享矩阵运算，`dist/game.js` 负责输入／UI／音效，`dist/index.html` 和 `dist/style.css` 为界面。静态服务器在 `scripts/serve.mjs`，测试在 `tests/engine.test.mjs`、`tests/terrain.test.mjs` 、`tests/character.test.mjs` 、`tests/director.test.mjs` 、`tests/progression.test.mjs` 和 `tests/pursuit.test.mjs`。

部署 `dist/` 内容到任意静态网站服务即可，资源全部使用相对地址，支持子目录部署。需要 WebGL 2 和硬件加速。

GitHub 中位于 `games/metro-rush-3d/`，保持独立启动和测试。个人站点 Eleventy 尚未配置该目录透传；独立试玩站点为 https://metro-rush-ming.mingxing47.chatgpt.site（需拥有站点访问权限）。
